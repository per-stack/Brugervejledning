# Genveje i FejerPro

## genveje ved brug af <Alt>
<alt> +
- t = Tur
- a = Arbejdsseddel
- l = Liste over besøg i afventer
- i = Liste over Besøg med Rest
- r = Regninger
- e = Klient transaktioner
- f = Afregninger ( Virker ikke giver Browser menuen )
- y = Rykkere
- n = Indbetalingsrapporter
- s = Stamkort
- o = Kommunelogin
- p = Profil
- m = Kommunal opkrævning
- å = Statestik på udført arbejde
- d = Tidsregistrering
- k = Kontakter
- g = Indstillinger
- h = Historik
- u = Klient Dokumenter
- b = Bruger Administration
- v = Varegrupper

##  Generelle genveje
- \<Pil ned> = bladre ned på side
- \<Pil op>  = Bladre op på side
- \<Page Up> = Bladre en side op
- \<Page Down> = Bladre en side ned
- \<Home> = Bladre til toppen af siden
- \<End> = Bladre til bunden af siden
