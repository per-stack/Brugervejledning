## Arbejdssedler 

### Rekvirering

- Bruger "Svendmodul" tema	
- Vis "Opdatér"- knap	
- Printer ikke arbejdssedler	
- Store og små bogstaver	
- Tur rekvireres kun én gang	
- Vis overbetalte ejendomme på printside	
- Vis saldo på arbejdsseddel	
  - none
  - only negative
  - all
- Skjul enheder	
- Beregn ikke kW enheder	
- Brug tildeling af rekvisitioner	
- Sidste måned for at oprette rekvisition for sidste år	- Dropdown
    - <Månederne>
- Brug gamle inkluderet ejendoms funktion	

### Tilsigning

- Brug tid på kalender	
- Vis alle tilsagte besøg til alle

- Brug "Opfølgning"

- "Tilsig med SMS" styrer besøgrapport
